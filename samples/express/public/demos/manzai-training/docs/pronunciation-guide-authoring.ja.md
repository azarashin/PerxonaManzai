# 発音ガイド作成手順

[English](pronunciation-guide-authoring.md) | 日本語

## 目的と対象

発音ガイドは、学習者がシナリオ言語を声に出して読むための補助である。表示専用メタデータであり、音声認識、alias、
採点、講評、アバターが読み上げる原文には影響しない。正とする発話は従来どおり`boke`または`text`である。同梱
カタログではすべての発話にガイドを必須とするが、外部および旧シナリオとの互換性のためSchema上は任意のままとする。

`pronunciationGuide`を追加できる場所は次の二つに限る。

- 対話の`boke`に対応する、beat直下のフィールド
- 選択肢の`text`に対応する、choice直下のフィールド

フィールドを指定する場合は`ja`、`en`、`zh`をすべて含める。タイトル、概要、講評、リアクション説明、aliasには
追加しない。

## 表記規則

| 言語 | 必須表記 | 例 |
| --- | --- | --- |
| 日本語（`ja`） | ひらがなによる全文の読み | `こんびにに れいぞうこ うってへんわ！` |
| 英語（`en`） | `/`で囲んだ一般米語の広いIPA表記 | `/kənˈviniəns stɔɹz doʊnt sɛl ɹɪˈfɹɪdʒəˌɹeɪtəɹz/` |
| 繁体字中国語（`zh`） | 声調記号付きの漢語拼音 | `Biànlì shāngdiàn cái bú huì mài bīngxiāng lie!` |

学習者が追いやすい語や句の境界に空白を置き、理解を助ける文の句読点は残す。すべてUnicode NFC形式で保存する。

日本語では、漢字、カタカナ、数字、助数詞を、そのローカライズ文で意図した実際の読みに変換する。演技上必要な
方言の読みは維持する。英語では狭い音声表記の角括弧ではなく音素表記のスラッシュを使い、短縮形を意図した自然な
発音で記述する。中国語の軽声には声調記号を付けず、`一`と`不`は意図した発話上の変調を一貫して示す。固有名詞や
地域差のある読みを推測しない。

## 作成手順

1. 三言語の`boke`と選択肢`text`を先に確定し、内容レビューを終える。
2. 宣言した移行範囲のキャラクター発話とプレイヤー選択肢へ、漏れなくガイドを追加する。
3. 各ガイドを同じ言語の原文と照合する。別言語の翻訳から読みを作らない。
4. JSON内の文字列をUnicode NFC形式に正規化する。
5. Schema検証とシナリオ品質監査を実行する。
6. シナリオプレビューで、シナリオ言語ごとに異なるプレイヤー母国語を選ぶ。初期状態でガイドが表示され、切替で
   非表示になり、母国語訳には別のガイドが付かないことを確認する。
7. 狭い画面とモバイル幅で改行と横方向のはみ出しを確認する。
8. IPA、声調、固有名詞、方言、複数の読みがある表現は、広範囲へ展開する前に各言語の熟達者が確認する。

レビュー済みの読みを用意できない場合は`pronunciationGuide`を省略する。不正確な学習情報を断定して表示するより、
ガイドがない方を優先する。

## 生成プロンプトに含める情報

Codex、Claudeなどへ発音ガイド追加を依頼する場合は、次を明記する。

- 対象シナリオまたはカテゴリの正確な範囲
- 既存の発話、alias、配点、講評、分岐、品質ポリシーを変更しないこと
- 上記の全文表記規則
- 英語の対象アクセントと中国語のローマ字表記方式
- 追加するガイドは三言語必須かつNFC形式であること
- 不確かな固有名詞、方言、別読みは推測せず、人手レビュー事項として報告すること
- Schema検証、品質監査、単体テスト、プレビュー、モバイル確認を実施すること

推奨依頼文:

```text
<シナリオまたはカテゴリ>へpronunciationGuideメタデータを追加してください。

編集前に、scenario.schema.json、scenario-catalog.schema.json、
scenario-generation-guide.md、scenario-quality-standards.md、
pronunciation-guide-authoring.ja.mdを読み、対象範囲の全多言語発話を確認してください。

制約:
- pronunciationGuideと、この作業に直接必要なテスト・文書だけを変更する。
- 発話、alias、配点、講評、状態、分岐、閾値、重大度、例外を変更しない。
- jaはひらがなの全文読み、enは/で囲んだ一般米語の広いIPA、
  zhは声調記号付き漢語拼音を使う。
- pronunciationGuideを追加する場合はja、en、zhをすべて含める。
- Unicode NFC形式で保存する。
- 曖昧な読みは推測せず、人手レビュー事項として報告する。
- npm run validate:scenarios、npm run quality:scenarios -- --summary、npm testを実行する。
- 発音ガイドのオン・オフをモバイル幅のシナリオプレビューで確認する。

ガイドの付与範囲、検証結果、残っている人手レビュー事項を返してください。
```

## 展開方針

同梱カタログの移行は完了しており、全52シナリオのキャラクター発話とプレイヤー選択肢に`pronunciationGuide`がある。
`convenience-store.json`は引き続き手作業で整備した参照例とする。同梱シナリオの網羅性と表記形式はカタログテストで
保証する。外部および旧シナリオとの互換性変更を製品として明示的に受け入れるまではSchema上は任意のままとし、
発音の正確性については各言語の熟達者によるレビューを継続する。
